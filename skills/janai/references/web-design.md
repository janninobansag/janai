# Website design references

Use this guide when building a website or substantially redesigning one. These sources offer different approaches, not one Janai visual style. Choose an example that fits the product, audience, content, and existing brand. A user-provided reference takes priority.

## Reference library

| --- | --- | --- |
| [Dribbble web design inspiration](https://dribbble.com/tags/web-design-inspiration) | Exploring several directions for a category | This is a changing gallery of independent shots. | [Royal Sites of Ireland](https://royalsites.ie/) | Heritage, cultural, travel, or editorial storytelling | Large expressive serif type on a dark opening scene, followed by warmer reading surfaces and narrative sections. Inspect how imagery, contrast, and scroll transitions support the story. |
| [Afternow](https://afternow.co/) | A B2B agency or service site that needs a confident identity and proof of work | Strong wordmark and compact navigation, generous white space, a focused media moment, large statement typography, then work and service evidence. Inspect how projects and calls to action guide the next step. |

These are observations of the sites, not reusable specifications. Their content and styling can change. Revisit the live source for the current design when tools allow.

## Turn a reference into a design decision

Inspect the actual page and one meaningful interaction. Record what you observed and why it suits this task:

- **Typography:** Identify display, body, and interface roles. Check family and weights from loaded fonts or CSS when available; otherwise describe the visual character without naming an unverified font.
- **Layout and spacing:** Compare page width, gutters, column relationships, section gaps, internal padding, and how they reflow on a narrow screen. Treat screenshot measurements as estimates.
- **Color and imagery:** Note background, text, accent, borders, and image treatment. Adapt the principle to the user's brand and assets instead of borrowing another brand's palette or pictures.
- **Interaction and motion:** Observe hover, focus, click, scroll, and transition behavior where possible. Note trigger and effect before implementing it. Keep controls usable with keyboard and reduced motion.

Translate the useful observations into a compact working direction and a consistent set of project tokens. Match the page's real content and primary task. On a redesign, retain existing brand elements and working flows unless the user asked to change them. Review the rendered result for generic hero, card, and gradient patterns that the chosen direction did not call for, then correct any weak hierarchy or spacing.
